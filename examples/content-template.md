# 数字花园内容模板（统一）

技术思考、开发日志、世界碎碎念共用**同一套 frontmatter**，只是正文写法和渲染形态不同。
写新内容 = 复制下面任意示例 → 改字段 → 存到对应目录。收集端自动按 `date` 倒序渲染，不用改任何代码。

## frontmatter 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | 技术思考必填；日志/碎碎念建议填 | 列表卡与预览卡显示的标题 |
| `date` | **必填** | `YYYY-MM-DD`，决定排序与年份分组 |
| `tags` | 可选 | 数组形式 `[标签1, 标签2]`，时间线取第一个作标签胶囊 |
| `readingTime` | 可选 | 数字，仅长文（技术思考）用，估算阅读分钟 |

正文第一段（`---` 之后的第一个非空段落）会被收集端自动当作**摘要**。

---

## 1. 技术思考（长文 → `tech-notes/文件名.md`）

```md
---
title: 为什么用 VitePress 搭数字花园
date: 2026-10-28
tags: [工程化, CI]
readingTime: 12
---

第一段：文章摘要，会自动显示在技术思考页的预览卡里。

## 背景

## 踩过的坑

## 结论
```

## 2. 开发日志（一句话流水 → `devlog/2026-10-28-主题.md`）

```md
---
title: 今日主题
date: 2026-10-28
tags: [开发]
---
一句话交代今天做了什么、卡在哪、有什么进展。一笔带过。
```

## 3. 世界碎碎念（一句吐槽 → `murmurs/2026-10-28.md`）

```md
---
title: 想说的话（可选，列表直接显示正文）
date: 2026-10-28
---
短小的一句吐槽 / 感叹 / 生活碎片，不用正经。
```

## 文件名约定

- 技术思考：语义化文件名即可（`ci-pipeline.md`），排序看 `date` 字段
- 开发日志：`YYYY-MM-DD-主题.md`
- 碎碎念：`YYYY-MM-DD.md`（同一天多条加 `-2` 后缀）

**注意**：这三个目录的内容只出现在各自的列表页里（时间线/导航），不会生成独立详情页。真正要写"能点进去细读"的完整文章，放 `tech-notes/`。
