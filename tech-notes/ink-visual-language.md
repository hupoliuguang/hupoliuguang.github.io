# 水墨国风卡牌 RPG 的视觉语言：从设定到落地

《古代卡牌生存》从立项那天起就是水墨国风。但这篇文章不聊"水墨好看"，聊的是把水墨从一张画变成一套**能批量生产、风格统一**的视觉语言——设定、卡面、UI、特效各自怎么落。

## 设定：留白与墨色

水墨的核心不是"画了什么"，而是"没画什么"。设定阶段固定了三件事：

1. **留白是构图的一部分**：卡面至少保留 30% 的空白，不给细节塞满。
2. **墨分五色**：浓、重、淡、清、焦。人物主笔墨色偏重，背景远山用淡墨，层次靠浓淡不靠线框。
3. **笔触要"松"**：AI 生成素材最大的问题是"画得太紧"（什么都清楚）。后期统一加一笔粗放的飞白，把松劲找回来。

## 卡面信息层级

卡牌是游戏里被看最多次的物件，信息层级必须稳定：

- 画面上方：卡牌名（书法字风格，短命名）。
- 画面主体：水墨立绘，人物与主题元素。
- 右下角：朱砂印章——这是身份标记，不是装饰。每张卡一个印，形成系列感。
- 底部：数值区，UI 层面处理，不进画面。

## UI 与水墨的融合

纯水墨 UI 会显得压抑。这里用了一个折中：**奶油纸色做底，马卡龙色做点缀**。

- 底：暖白纸色，模拟宣纸质感，全局统一。
- 点缀：珊瑚、薄荷、奶黄三个低饱和色，用在按钮、标签、进度条。
- 字体：标题用偏手写的书法感字体，正文用常规黑体保证可读性。

这套组合的好处是：既有水墨的"雅"，又有游戏 UI 需要的"亮"和"点得下去"。

## 落地：AI 素材 + 手工修正

生产流程目前是：

1. AI 生成底图（构图、氛围打底）。
2. 手工修正关键部位（人物面部、手部、主体边缘）。
3. 统一加纹理（纸纹、颗粒）与飞白笔触。
4. 特效层做水墨化：溅墨、晕染用粒子实现，避免生硬的矩形光效。

## 风格一致性 Checklist

任何新素材进项目前过一遍：

- [ ] 留白是否充足（截图缩小看整体，仍能一眼看懂主体）
- [ ] 墨色层次是否在（浓淡至少三档）
- [ ] 有没有多余的细碎细节（有就删）
- [ ] 纸纹/颗粒是否统一
- [ ] 印章位置是否在右下角

这套清单把"风格统一"从感觉变成了检查项，新人也能照着过。
